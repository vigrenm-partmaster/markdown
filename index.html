How to Use

  1. Open your .md file in Notepad (or any text editor)
  2. Select all the text (Ctrl+A) and copy it (Ctrl+C)
  3. Paste it into the input box on the left (Ctrl+V) — it renders automatically
  4. Read the nicely styled result in the Rendered Preview panel
  5. Use Print / Save PDF to save or print a clean copy
  6. Pick a look you like from the Theme menu (top right)
